## Rollback
Solo CODICE (lo script stampa i comandi esatti a fine run):
```powershell
$nssm = 'C:\ProgramData\chocolatey\bin\nssm.exe'
& $nssm stop PresenzeHR confirm
$bak = Get-ChildItem 'E:\www\hr.bak-*' -Directory | Sort Name -Desc | Select -First 1
Remove-Item 'E:\www\hr' -Recurse -Force
Move-Item $bak.FullName 'E:\www\hr'
& $nssm start PresenzeHR
```
**DB: nessun rollback.** Le aggiunte di schema sono additive — il codice vecchio le ignora, quindi il rollback del solo codice è sicuro. (Per tornare a uno snapshot DB, usa il backup di `E:\HR\backups` fatto allo Step 2.)
